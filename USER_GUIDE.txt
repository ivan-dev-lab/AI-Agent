РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ
Бот для управления учебными группами и заданиями

1) Что делает бот
- Хранит учебные группы (классы) и список студентов.
- Позволяет преподавателям выдавать задания всей группе или отдельным студентам.
- Помогает студентам видеть задания и дедлайны, получать напоминания.
- Даёт локальному администратору инструменты для управления доступом.

2) Как начать работу
- Откройте бота в Telegram и нажмите Start (/start).
- Если вы студент: используйте персональную ссылку приглашения от преподавателя/админа.
- Если вы преподаватель: вас должен назначить локальный админ по Telegram ID.
- Если вы локальный админ: введите пароль администратора при первом входе (пароль задается в файле .env LOCAL_ADMIN_PASSWORD)
- После регистрации откроется меню вашей роли.

3) Термины
- Университет: организация, где назначаются преподаватели и студенты.
- Группа/класс: учебная группа студентов (в интерфейсе встречаются оба слова).
- Задание: описание работы + дедлайн.

4) Роль: локальный администратор
Главное меню делится на разделы «Основные» и «Информационные».

Основные:
- Создать университет и назначить себя локальным администратором.
- Назначить преподавателя: выбрать университет, ввести Telegram ID и имя преподавателя.
- Редактировать преподавателей: переименовать или удалить из ваших университетов.

Информационные:
- Списки преподавателей по группам.
- Списки студентов по группам.
- Список локальных администраторов.

5) Роль: преподаватель
Меню преподавателя:
- Добавить студента.
- Редактировать студентов.
- Создать группу.
- Редактировать группу (добавить/удалить).
- Добавить задание.
- Список заданий.

Добавить студента:
1) Введите ФИО.
2) Выберите группу.
3) Бот выдаст ссылку‑приглашение. Передайте её студенту.

Создать группу:
- Просто отправьте название группы одним сообщением.

Редактировать студентов:
- Выберите группу → студента → действие:
  - Изменить ФИО.
  - Перенести в другую группу.

Редактировать группу:
- Выберите группу → действие:
  - Удалить группу (убираются все привязки студентов).
  - Удалить студента из группы.
  - Добавить студента в группу.
  - Переименовать группу.

Добавить задание:
1) Выберите группу.
2) Укажите охват: всей группе или выбранным студентам.
3) Введите название задания.
4) Укажите дедлайн в формате DD.MM.YYYY HH:MM
   (время по часовому поясу группы, обычно UTC+5).
5) Добавьте описание (или «-», чтобы оставить пустым).

Список заданий:
- Выберите группу → «Задания для всей группы» или «Задания для студентов».
- Откройте задание: можно изменить название/описание/дедлайн или удалить.
- При изменении задания студенты получают уведомления.

6) Роль: студент
Меню студента:
- Мои задания.
- Мои преподаватели.
- Мои группы.
- Расписание.
- Информация.

Мои задания:
- Список разделяется на просроченные и актуальные.
- Нажмите на номер задания, чтобы открыть карточку.
- В карточке доступна кнопка «Спросить у нейросети»:
  задайте вопрос — бот пришлёт ответ.

Расписание:
- Показывает ближайшие дедлайны.

7) Уведомления и дедлайны
- При назначении задания приходит уведомление.
- При изменении задания приходит уведомление.
- Напоминания приходят за 24 часа до дедлайна.
- Дедлайны показываются в часовом поясе UTC+5 (местное время по Екатеринбургу).
